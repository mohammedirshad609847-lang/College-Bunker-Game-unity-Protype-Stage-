# College Bunker Game (unity) (Protype Stage)
Ever wanted to sneak out of a boring lecture? 🎒🏃‍♂️ I'm building a stealth game in Unity about exactly that! Here is the very first gameplay footage of my College Bunking game.  I’ve been learning game development, and getting this Stage 1 prototype working has been incredibly rewarding. The guards now have working vision cones, they will actively chase you if spotted, and you have to find keys to unlock gates. Best of all? You can now throw items to distract the guards and clear a path!  It looks like just cubes right now, but the actual gameplay logic is working perfectly. Check it out and let me know if you would survive this campus! 👇
